# 视频提示词库

共 80 条。先选题材，再选细分，最后读 3–5 条原文。

- [人物与角色](人物与角色.md)：16 条。以人物身份、表演和日常生活为主体。
- [剧情与动作](剧情与动作.md)：7 条。人物发生冲突、追逐、相遇或情节变化。
- [产品与广告](产品与广告.md)：11 条。商品、品牌、使用体验或广告表达。
- [动物与奇幻生物](动物与奇幻生物.md)：4 条。真实动物或虚构生物是主体。
- [场景与风光](场景与风光.md)：24 条。环境、建筑或空间变化是主体。
- [特效与转场](特效与转场.md)：4 条。画面变化或视觉效果本身是主题。
- [实验与抽象](实验与抽象.md)：12 条。概念、抽象形式、教学演示与技术实验。
- [其他](其他.md)：2 条。题材尚不明确的参考；保留原文供人工判断。
